# Шрифты

Программа сама ищет шрифт в этом порядке: Montserrat → Inter → Roboto → Poppins →
Open Sans → системный Liberation/DejaVu. Шрифты без нужных символов пропускаются
автоматически (например, Poppins не умеет кириллицу — для русского текста он
будет пропущен).

Чтобы использовать свой шрифт, просто положите `.ttf` или `.otf` в эту папку —
он появится в выпадающем списке в интерфейсе. Или запустите `./download_fonts.sh`,
чтобы скачать Montserrat / Inter / Roboto с поддержкой кириллицы.
